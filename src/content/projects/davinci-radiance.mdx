## Overview

DaVinci Radiance needed a **high-trust**, **high-clarity**, and **conversion-optimized** website to help new teeth-whitening clients understand the process, view real results, and call the correct location directly from mobile.

The solution was a **custom Astro build**, engineered for:

- **Dual-location routing** with tap-ready CTAs  
- **Local SEO dominance** via full `LocalBusiness` structured data for each location  
- **Ultra-fast image optimization** using Astro’s built-in pipeline  
- **A clean, medical-calming visual system** with soft gradients, precise spacing, and clear content hierarchy  
- **A mobile-optimized navigation system** designed for quick decision-making  

Every major page — Home, Process, Results, FAQ, About — was built with purpose: reduce friction, build trust, and prompt contact.
